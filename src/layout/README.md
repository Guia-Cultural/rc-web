# Layouts da aplicação

Esta pasta fica reservada aos layouts que envolverão conjuntos de páginas, por exemplo `PublicLayout` e `AdminLayout`.

A Home atual mantém Header e Footer dentro de `pages/Home/Home.jsx`, pois ainda não existe outra página pública funcional que compartilhe esse mesmo shell. Quando Community, Location e Recommend estiverem implementadas, a estrutura poderá ser movida para um layout público compartilhado sem duplicação.
